# Recommendation-System-using-Deep-learning

This project is a Recommendation System built using Python, Streamlit, and TensorFlow that suggests personalized Netflix content to users. The system leverages deep learning techniques on the Netflix Content 2023 Kaggle dataset to analyze user preferences and recommend movies/TV shows accordingly.

# Features

# Data Preprocessing & Analysis:
Cleaned and processed Netflix dataset for building the model.
 
 # Deep Learning Model:
 Implemented a recommendation system using TensorFlow for accurate predictions.
 
# Interactive Web App:
Built with Streamlit to provide an easy-to-use interface for exploring recommendations.
 
# Content-Based Filtering:
Suggests movies and shows similar to user preferences.

# Tech Stack

Python
TensorFlow (Deep Learning Framework)
Streamlit (Frontend Web App)
Pandas, NumPy, Scikit-learn (Data Handling & Preprocessing)

# Dataset

The dataset used is Netflix Content 2023 from Kaggle, containing metadata about movies and TV shows available on Kaggle.
